# Synthetic hobby-shop fixtures

Generated with `node --import tsx scripts/generate-hobby-shop.ts --shop jewellery-maker --seed 7`.
All names, orders, buyers and addresses are synthetic. Fees are estimates only, using the published [UK merchant fee schedule](https://www.paypal.com/uk/webapps/mpp/merchant-fees) and [US business fee schedule](https://www.paypal.com/us/business/paypal-business-fees), not an account-specific quote.

Each preset has the app layout, a PayPal-activity layout, an expected-card file, and (for larger shops) a later `after` upload.
