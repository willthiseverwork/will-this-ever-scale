# Billing

The offer for a seller's own shop is a free 30-day trial with a card at checkout, then US$14.99 per month. Cancel before the trial ends to avoid a charge. The demo is free; judges can use the access code described in the [README](../README.md) for access without checkout.

Billing is off unless `WTES_BILLING_ENABLED=true` and `WTES_BILLING_STARTS_AT` is a valid, non-future timestamp. When enabled, checkout verifies that the dedicated Paddle price is active, USD 14.99 monthly, and has a free 30-day trial requiring a payment method. Checkout can be started without waiting for an older workspace trial to expire. A completed checkout alone does not establish access: server-side transaction and subscription verification and signed webhooks govern the subscription state. Trialing and active subscriptions can use gated features; when billing is off, workspace saves remain available as a free beta. Judge access is separate from billing.

Use dedicated WTES settings: `WTES_PADDLE_ENV`, `WTES_PADDLE_API_KEY`, `WTES_PADDLE_CLIENT_TOKEN`, `WTES_PADDLE_PRICE_MONTHLY`, `WTES_PADDLE_WEBHOOK_SECRET`, `WTES_BILLING_STORE_ID`, and an independent `WTES_BILLING_SECRET` of at least 32 bytes. Billing storage uses Vercel OIDC; WorkOS and workspace settings are separate. Configure the provider webhook at `/api/billing/webhook` for the intended host. See [.env.example](../.env.example) and [the sandbox harness](billing-test.md).

Full refunds and chargebacks can place access on hold; reversals require a fresh provider check. Webhooks are signature checked, bound to the server-created transaction, and ordered by provider event time. Confirm duplicate, out-of-order and replacement-subscription behavior with real sandbox notifications.

`/billing` provides checkout and the authenticated customer portal when configured. Workspace deletion does not cancel a subscription. Verify the dedicated price, checkout, webhook delivery, entitlement, cancellation, renewal, refunds, and portal behavior in the appropriate sandbox before enabling billing. Source code and mocked tests do not establish a successful provider lifecycle or live payment. No payment is needed for the demo or judge access.
