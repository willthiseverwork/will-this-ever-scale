# Dependency security — 31 October 2026

A fresh registry-backed `npm audit` on 31 October 2026 reports **20 affected dependency entries: 17 high and 3 moderate**, with no critical entries. An `npm audit fix --dry-run --package-lock-only --ignore-scripts` against the registry reported **0 added, 0 removed and 0 changed**, with the same 20 entries. No dependency or lockfile changes were therefore made in this review. npm's proposed remediations include downgrading the PayPal toolkit, Blob or the OIDC credentials provider, or migrating root Zod to version 4; these are not routine compatible patches. No forced fix or unverified override was applied. Audit counts are dependency entries, not a count of distinct underlying advisories.

The high entries include Zod, provider utilities, the PayPal toolkit and its LangChain, AI SDK, mathjs, jsondiffpatch, undici and busboy dependency paths, and the Blob/OIDC dependency path. The three moderate entries are the Bedrock provider, Anthropic provider and UUID. The npm audit report is a dependency-path assessment; it does not establish that every vulnerable operation is reachable in this application.

- **Zod collection exhaustion:** root Zod 3.25.76 is used by public API validation and the PayPal toolkit; Blob's CLI-config has an independently pinned Zod 4.1.11. The patched advisory range is Zod 4.6.6 or later, outside the root major and the CLI-config exact pin. All app JSON routes now read and cap incoming bytes before parsing and validation (1–64 KiB depending on route), including chunked requests. This reduces input-driven exhaustion; it is not a proof that all Zod paths or external provider responses are safe. Migrate and integration-test Zod and its callers when their dependencies support a compatible version.
- **PayPal toolkit tree:** the app imports only the toolkit's AI SDK adapter and invokes its invoice-list tool; it does not expose an arbitrary toolkit dispatcher or use the LangChain, OpenAI, MCP, UI-rendering, expression-evaluation, or prompt-deserialization adapters. The package nevertheless installs old `@langchain/core`, `ai` 4, `jsondiffpatch`, `mathjs`, OpenAI SDK and transitive packages flagged by audit. Some code is bundled in the imported adapter, so these boundaries reduce exposure but do not establish non-reachability of every vulnerable function. Patched versions require crossing pinned or major-version boundaries; assess an upstream toolkit release or replacing the single read adapter, with sandbox compatibility tests, before applying overrides.
- **Amazon Bedrock provider:** version 3.0.142 is the matching provider-interface generation for AI SDK 5. It adds advisory paths through its pinned provider-utils 3.0.43 and undici/fastify-busboy. The app sends a small JSON prompt and does not parse user-supplied multipart through this adapter, but these dependencies remain present and that does not prove every vulnerable path unreachable. The provider is used only when configured; its production activation and access controls must be assessed from the current deployment, not inferred from this dependency audit.
- **Blob/OIDC:** the private reminder store uses `@vercel/blob` 2.8.2; its OIDC/CLI-config tree carries the pinned vulnerable Zod 4.1.11. The reminder route limits the input to 2 KiB and validates the exact fields. A compatible upstream CLI-config update remains needed.
- **UUID:** the moderate advisory enters through the toolkit's LangChain tree; the vulnerable buffer-write use is not invoked by app code. It remains an installed dependency and is not claimed fixed.

The earlier provider addition passed TypeScript, a 42-test suite and a production build at that earlier revision. No local tests, build or server were run for this review, as requested. The audit and compatible-fix preview do not verify deployed behavior or attack resistance. For a future compatible upstream release or dependency migration, rerun the registry audit and the full cloud checks, including PayPal sandbox, Bedrock provider selection and request-size limits, before release.
